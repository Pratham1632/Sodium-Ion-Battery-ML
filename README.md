# Evaluating Sodium Ion Battery Performance using Machine Learning

## 📌 Overview
This project evaluates the performance of a Sodium-Ion Battery using Machine Learning
regression models implemented in MATLAB. The study focuses on predicting and analyzing
battery behavior under different operating conditions such as voltage, temperature,
charge voltage, time step, and record number.

Regression models including Fine Tree and Linear Regression were trained using MATLAB’s
Regression Learner, and model performance was evaluated using RMSE.
